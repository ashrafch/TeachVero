# Changelog

Versions describe reviewable product increments. A candidate is not a published release.

## [0.2.0] - Unreleased

### Added

- Teacher student records, manual package allocations, lesson scheduling, transactional credit reservations/cancellation and private follow-up notes.
- Student-owned lesson/credit views, lesson detail routes, FAQ and compatible learning/legal URL redirects.
- Interactive learning-goal selection and Italian phrase preview.
- Dedicated teacher/student workspaces, URL-addressable sections and student search.
- PostgreSQL integration coverage and expanded responsive, authorization, accessibility and end-to-end checks.
- Branch/PR conventions, version consistency checks and a pull request template.

### Changed

- Shortened the homepage, promoted clear learning choices and harmonized public typography/navigation.
- Replaced stacked workspace forms with focused views and a separate student profile.
- Bundled the Open Graph font locally and updated recovery, design and deployment documentation.

### Fixed

- Preserved private teacher follow-up fields when a public lead submits another request.
- Enforced HTTP redirects for canonical aliases, guarded final-credit concurrency and kept teacher notes out of student responses.

### Preview boundaries

Payments, external calendars and email are disabled. Prices, teacher photography, legal approval and production account onboarding remain pending. No production release or deployment is represented by this version.

## [0.1.0] - Historical baseline

Existing public teaching site, local authentication, package/resource editing, inquiries and learning activities. Imported from the repository history; no retrospective claim about release publication or test execution.
