# SEO and internationalization
Decide target audiences and locales with the business before translating; English-primary is a provisional assumption. Use one locale-routing approach consistently.

- Localize navigation, pricing number formats, dates/timezones, metadata, errors, confirmation emails and lesson copy where applicable.
- Generate canonical, hreflang per actual translated URL, robots, sitemap, social previews, proper metadata and headings.
- Favor useful original pages over thin templated articles. Each indexed page must answer real learner intent and link to a relevant lesson offer.
- Structured data must describe facts actually visible on the page (Person, Organization if appropriate, Course where appropriate, BreadcrumbList, FAQ only if eligible and accurately represented). Never invent rating/review schema.
- Check indexable vs authenticated routes; prevent student dashboards and admin pages from appearing in search.
- Audit CLS/LCP/INP, font and image loading, crawlability, accessible internal navigation and clean slug behavior.

Output: SEO checklist with tested URLs, localization matrix and evidence of pass/fail; no ranking promises.
