# Mobile conversion
Most TeachVero discovery originates from mobile social traffic. Optimize intent continuity, not clickbait.

1. Model path: social link -> relevant landing -> value/teacher credibility -> lesson/package -> booking inquiry/checkout -> confirmation.
2. Above the fold on 360–390px: clear teacher identity, what is taught, for whom, primary CTA, trust cue that is true. Keep navigation compact but discoverable.
3. Link-in-bio and campaign pages must match the promise of the original Reel/post, with campaign attribution only where consent rules permit.
4. Specify sticky booking CTA only when it doesn't hide content, cookies, keyboard or accessibility controls.
5. Make price, duration, format, timezone, availability status and cancellation policy unambiguous; unknown values must be editable configuration or visibly labelled provisional drafts, not fabricated offers.
6. Check autofill, input types, errors beside fields, server validation, keyboard focus, screen reader labels, spacing and minimum comfortable touch size.
7. Write Playwright scenarios at mobile viewports for each primary CTA; validate no horizontal overflow and no broken flow.
8. Track funnel events with a consent-aware analytics layer and stable names, never sending PII into analytics.

Deliver: annotated funnel, responsive screenshots, issues ranked by severity and tested acceptance criteria.
