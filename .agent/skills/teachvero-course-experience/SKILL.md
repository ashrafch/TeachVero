# Educational product design
Audience: adults learning Italian as a foreign language, variable proficiency. Map lessons to CEFR A1–C2 where defensible.

## Workflow
- Start with an explicit measurable learning objective, prerequisite, time estimate, skill category, language of instruction, expected outcome.
- Organize learning content into discoverable themes: greetings, practical conversation, travel, grammar, pronunciation, culture, exam preparation only when genuinely offered.
- Create accessible explanations with worked examples and one meaningful interactive activity per lesson.
- Quizzes require deterministic correct answer(s), sensible distractors, feedback explaining why, retry, keyboard access and progress saving when signed in.
- Offer free sample content without dead-end gates; make the path to personalized lessons useful but not coercive.
- For dashboard data model: Lesson, Module, Activity, Attempt, Resource, Progress, Enrollment; define authorization per record.
- Support content revisions, draft/published states, and safe server-side rendering. Never let model-generated lesson text silently publish without teacher review.
- Review pedagogy and language accuracy with Veronica before launch; no invented qualification or CELI/CILS accreditation.

Definition of done: working activity, mobile UX, realistic seeded demo content clearly labeled as sample, tests for grading/progress/permissions.
